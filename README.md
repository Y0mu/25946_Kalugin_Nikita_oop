# Код по занятиям ООП

Здесь лежат решения всех заданий по курсу. Код соответствует лекциям из
папки `lesson/` и заданиям из папки `tasks/`.

Эта папка — корень репозитория на GitHub
(https://github.com/Y0mu/25946_Kalugin_Nikita_oop), поэтому на GitHub
`lesson_01` ... `lesson_05` лежат сразу в корне, без лишней вложенной папки.

а в каждой папке задания — файл `build.txt` с командами сборки.

## Что за файлы внутри задания

Почти везде структура одинаковая:

* `main.cpp` — точка входа (там, где по заданию нужен ввод с клавиатуры, он есть);
* `*.h` — объявления функций, `*.cpp` — их реализации;
* `*.h` без `main.cpp` — задания, где всё делается в одной программе;
* `CMakeLists.txt` — только в заданиях занятия 5.

Комментарии в коде на русском, объясняют происходящее по шагам.

## Как собрать задания занятий 1–4

Это обычные программы на C++17, CMake для них не нужен.

MSVC (Developer PowerShell):

```
cl /std:c++17 /EHsc /W4 main.cpp other_file.cpp /Fe:app.exe
.\app.exe
```

g++:

```
g++ -std=c++17 -Wall -Wextra main.cpp other_file.cpp -o app
./app
```

В каждой папке задания в `build.txt` выписана точная команда с нужным списком файлов.

## Как собрать задания занятия 5

Только командная строка (IDE использовать нельзя по условию задания):

```
cmake -S . -B build
cmake --build build
```

Подробности, включая запуск тестов GoogleTest двумя способами, — в `lesson_05/README.md`
и в `build.txt` внутри каждого проекта.

## Если русские буквы в выводе программ выглядят странно

Это особенность консоли Windows (кодировка), а не ошибка в программах.
Включить UTF-8 можно командой:

```
chcp 65001
```

На работу кода это не влияет: комментарии на русском, вывод программы понятен и так.
