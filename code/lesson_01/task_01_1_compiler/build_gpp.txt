ЗАДАНИЕ 01.I. СБОРКА ИЗ КОМАНДНОЙ СТРОКИ (g++, вариант для Linux/WSL/MinGW)
==========================================================================

1) Стандарт + предупреждения + макрос + только компиляция + имя объектного файла:

   mkdir -p obj
   g++ -std=c++17 -Wall -Wextra -Werror -DDEBUG_LOG -c source.cpp -o obj/source.o

   Разбор флагов:
   -std=c++17  - стандарт языка C++17
   -Wall -Wextra - высокий уровень предупреждений
   -Werror     - предупреждения как ошибки
   -DDEBUG_LOG - определяем макрос DEBUG_LOG
   -c          - только компиляция (получаем объектный файл .o)
   -o obj/source.o - имя и место объектного файла

2) Без макроса отладочный вывод исчезнет:
   g++ -std=c++17 -Wall -Wextra -Werror -c source.cpp -o obj/source.o

3) Сборка из объектного файла с заданием имени программы:

   g++ obj/source.o -o app

4) Запуск:

   ./app
