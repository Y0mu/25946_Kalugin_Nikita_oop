ЗАДАНИЕ 01.I. СБОРКА ИЗ КОМАНДНОЙ СТРОКИ (MSVC, Visual Studio Developer PowerShell)
=====================================================================================

Все команды выполняются из папки, где лежит source.cpp.
IDE (Visual Studio) не открываем вообще — только командная строка.

1) Выбор стандарта языка + уровень предупреждений + предупреждения как ошибки
   + макрос препроцессора + только компиляция (/c) + папка для объектного файла:

   cl /std:c++17 /EHsc /W4 /WX /DDEBUG_LOG /c source.cpp /Fo:obj\source.obj

   Разбор флагов:
   /std:c++17  - стандарт языка C++17
   /EHsc       - стандартная обработка исключений C++
   /W4         - высокий уровень предупреждений
   /WX         - любое предупреждение становится ошибкой сборки
   /DDEBUG_LOG - определяем макрос DEBUG_LOG (он используется в #ifdef)
   /c          - только компиляция, объектный файл без линковки
   /Fo:obj\source.obj - куда положить объектный файл

   Папку obj надо создать заранее:  mkdir obj

2) Если запустить ту же команду БЕЗ /DDEBUG_LOG, то отладочный вывод пропадёт:
   cl /std:c++17 /EHsc /W4 /WX /c source.cpp /Fo:obj\source.obj

3) Сборка (линковка) из готового объектного файла с заданием имени результата:

   link obj\source.obj /OUT:app.exe /Fe:app.exe

   Или одной командой через компилятор:
   cl obj\source.obj /Fe:app.exe

4) Запуск:

   .\app.exe

Ожидаемый вывод (когда собирали с /DDEBUG_LOG):
   Debug mode
   Number: 5
   Value: 42
