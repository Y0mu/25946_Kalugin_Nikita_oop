## 02.I. Аргументы функций

1. Изменения аргумента видны снаружи → параметр передаём по ссылке `int&`,
   и при этом копии не создаются.
2. Изменять значения внутри функции нельзя, но и копирования быть не должно →
   параметр передаём по константной ссылке `const int&`.

## 02.II. Модифицированная функция

Имя, тип возвращаемого значения и список аргументов у «модифицированной» функции
совпадают с «требуемой», то есть сигнатуры одинаковые: `int Sum(int&, int&)`.
Чтобы не было конфликта имён, функции разложены по пространствам имён
`required` и `modified`.

## 02.III и 02.IV

Функции переписаны через шаблоны, поэтому они работают и с `int`, и с `double`
и с любым другим типом, для которого определён оператор `+`.
