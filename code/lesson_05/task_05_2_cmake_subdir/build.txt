ЗАДАНИЕ 5.II. СБОРКА ЧЕРЕЗ CMAKE (библиотека в поддиректории)
=============================================================

Структура проекта:
   CMakeLists.txt          <- корневой, подключает поддиректорию
   main.cpp
   my_lib/
       CMakeLists.txt      <- создаёт цель mylib
       my_lib.h / my_lib.cpp
       my_random.h / my_random.cpp

Отличие от 5.I: в корневом CMakeLists.txt появилась строка add_subdirectory(my_lib),
а сами файлы библиотеки переехали в поддиректорию.

Сборка (из корня проекта):
   cmake -S . -B build
   cmake --build build
   cmake --build build --config Release      (для MSVC)

Запуск:
   .\build\Debug\exec_trg.exe
   .\build\exec_trg.exe
   ./build/exec_trg
