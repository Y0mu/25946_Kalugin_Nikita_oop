ЗАДАНИЕ 5.IV. ОПЦИЯ ВКЛЮЧЕНИЯ/ВЫКЛЮЧЕНИЯ ТЕСТОВ
================================================

В корневом CMakeLists.txt появилась строка:

   option(BUILD_TESTS "Собирать тесты вместе с библиотекой" ON)

и тесты подключаются только внутри if(BUILD_TESTS).

ВАРИАНТ 1. Собираем вместе с тестами (по умолчанию):
   cmake -S . -B build
   cmake --build build
   cd build && ctest --output-on-failure

ВАРИАНТ 2. Собираем без тестов:
   cmake -S . -B build-no-tests -DBUILD_TESTS=OFF
   cmake --build build-no-tests

   При конфигурации CMake напишет:
      -- BUILD_TESTS = OFF: собираем без тестов
   а цель my_tests вообще не появится. GoogleTest даже не будет скачиваться.

Проверить, какие цели есть в собранном проекте, можно так:
   cmake --build build --target help

Как выключить опцию уже у готовой сборки: нужно заново сконфигурировать
и пересобрать, например:
   cmake -S . -B build -DBUILD_TESTS=OFF --fresh
