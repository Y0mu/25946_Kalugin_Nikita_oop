ЗАДАНИЕ 5.V. ШАБЛОННАЯ БИБЛИОТЕКА + ТЕСТЫ + ОПЦИЯ
==================================================

Структура проекта:
   CMakeLists.txt
   main.cpp
   include/my_lib/my_lib.h      <- шаблоны библиотеки (заголовки)
   include/my_lib/my_random.h   <- шаблон с рандомом
   src/my_lib.cpp               <- обычная функция Version()
   my_lib/CMakeLists.txt        <- цель mylib
   tests/CMakeLists.txt         <- цель my_tests (подключается при BUILD_TESTS)
   tests/my_tests.cpp

Ключевая мысль задания: шаблонные функции должны быть видны там, где их
вызывают, поэтому их реализация лежит в заголовках, а не в .cpp.
Заголовки отдаются наружу через target_include_directories(mylib PUBLIC include).

СБОРКА С ТЕСТАМИ:
   cmake -S . -B build
   cmake --build build
   cd build
   ctest --output-on-failure
   cd ..
   .\build\tests\Debug\my_tests.exe        (MSVC)
   .\build\tests\my_tests.exe              (MinGW/Ninja)

СБОРКА БЕЗ ТЕСТОВ:
   cmake -S . -B build-no-tests -DBUILD_TESTS=OFF
   cmake --build build-no-tests

ЗАПУСК ПРОГРАММЫ:
   .\build\Debug\exec_trg.exe
   ./build/exec_trg
