## Задание 01.I. Компилятор

Нужно показать, что умеем собирать программу руками, без IDE:

1. выбор стандарта языка — `/std:c++17` (MSVC) или `-std=c++17` (g++);
2. уровень предупреждений — `/W4` (`-Wall -Wextra`) и `/WX` (`-Werror`);
3. макрос препроцессора — `/DDEBUG_LOG` (`-DDEBUG_LOG`);
4. компиляция без линковки — `/c` (`-c`);
5. имя и расположение объектного файла — `/Fo:` (`-o`);
6. сборка из объектного файла (линковка);
7. имя итогового исполняемого файла — `/Fe:` (`-o`).

Готовые команды лежат в `task_01_1_compiler/build_msvc.txt` и `build_gpp.txt`.

## Задание 01.II. Функции и организация кода

1. Заголовочный файл (`sum_required.h`) + файл с реализацией (`sum_required.cpp`) «требуемой» функции, вызов из `main.cpp`.
2. Такие же два файла для «модифицированной» функции (`sum_modified.h`, `sum_modified.cpp`) — она добавляет случайное число в половине случаев.
3. Оба вызова есть в `main.cpp`.

Входные значения вводятся с клавиатуры в `main.cpp`.
