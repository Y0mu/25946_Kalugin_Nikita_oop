# Занятие 4. Алгоритмы

Материалы: `lesson/OOP_04.pdf`, задания: `tasks/Задания OOP_04.txt`.

| Папка | Задание |
|---|---|
| `task_04_1_files_algorithms/` | 4.I — чтение двух наборов чисел из файлов, подсчёт частот двумя способами, суммы |
| `task_04_2_homework/` | 4.II — домашнее задание: `std::accumulate` с бинарной операцией, дубликаты, пересечение |

## Данные

В обеих папках лежат файлы `data1.txt` (больший набор) и `data2.txt` (меньший набор).
В реальном задании ссылки на файлы давал преподаватель в shared — здесь они такие же
по смыслу: набор целых чисел, где часть значений повторяется много раз.

## Что происходит в программах

**4.I**
1. два файла читаются в два вектора, больший вектор становится «первым»;
2. выводится количество чисел в каждом векторе;
3. частоты считаются двумя способами: `std::map` в цикле `for` и
   `std::for_each` с лямбдой; результаты сравниваются, чтобы было видно, что способы эквивалентны;
4. сумма всех значений — двумя вариантами `std::accumulate`
   (по умолчанию и со своей лямбдой / `std::plus<int>`);
5. сумма первых 10 элементов — тоже `std::accumulate`, но циклов в коде нет вообще,
   просто передаём итератор на 11-й элемент как конец диапазона.

**4.II**
1. результат бинарной операции (вычитания) для каждого вектора через `std::accumulate`;
2. числа второго вектора с частотой ≥ 2 и числа первого вектора с частотой > 3;
3. пересечение этих множеств, посчитанное двумя способами:
   циклом `for` с итераторами и `std::copy_if` с лямбдой.

## Запуск

Программу нужно запускать из папки, где лежат `data1.txt` и `data2.txt`
(файлы читаются по относительному пути).

```
g++ -std=c++17 -Wall -Wextra main.cpp -o app
./app
```
